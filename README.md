# spore-game-copy

## 🎮 Sporadium: the game

[`game/`](game/README.md) is **Sporadium**, a mobile-first evolution game inspired by the stage structure of *Spore*, with its own names, art and rules. It starts with a single cell in a tide pool. You walk ashore, lead a tribe, unite a planet, and take to a spiral galaxy of about 840 stars. Every creature, vehicle, building and starship is built from parts in one shared touch editor. Everything you see and hear is generated procedurally.

```bash
cd game && npm install && npm run dev   # then open the printed URL on your phone or desktop
```

| Stage | Highlights |
|---|---|
| 🦠 Cell | Eat plants or meat, avoid giants, collect meteor shards for 12 stacking cell parts, and earn your diet card |
| 🦎 Creature | Island with 10 species nests, a socialize rhythm and combat, Titans, bone piles, migrations, and a pack of up to 3 |
| 🔥 Tribal | Mini-RTS: food economy, 9 tool types, a tribal outfitter, rhythm concerts or raids against 4 rival tribes |
| 🏙️ Civilization | Planet RTS: spice geysers, a city planner with adjacency, military/religious/economic capture, and superweapons |
| 🚀 Space | About 840 stars, 14–18 AI empires, the Hollow, landing on planets to hunt for life, terraforming, colonies, a spice market, the Xeno-Lab, missions, ranks, and the trip to the core |

See [`game/docs/DESIGN.md`](game/docs/DESIGN.md) and [`game/docs/ARCHITECTURE.md`](game/docs/ARCHITECTURE.md).
